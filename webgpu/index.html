Reduced MHD in the browser — WebGPU pseudospectral solvers

a browser port of the jax_rmhd solver · fp32 · no server, no build step · about / README

Two live pseudospectral solvers for reduced MHD, running entirely on your GPU through WebGPU: the same equations, dealiasing, LSRK33 integrating-factor stepper and (optional) Elsasser Ornstein–Uhlenbeck forcing as the JAX code they were ported from. Both pages ship the fp64 reference vectors generated from jax_rmhd itself and a Self-test button that runs them through the same GPU pipelines as production. They are demos, not science runs: WebGPU has no float64.

2D RMHD →

rfft2 spectral in (x,y), 128²–512² or a wide 4π×2π box. Vorticity / current / potentials / velocity and magnetic field with arrow and field-line overlays, energy trace, shell-binned spectra, cut trace. Forced runs show the 2D inverse cascade piling magnetic energy up at the box scale; the equilibrium presets show shear-flow roll-up and magnetic reconnection instead.

3D RMHD, spectral z →

rfftn over (z,x,y), 64²×32 to 256²×64. The Alfvén coupling ±i·kz is applied exactly by a closed-form 2×2 wave propagator, so there is no wave CFL. z-slice or three-face cube view, perpendicular and parallel spectra.

Each app has a preset dropdown in its top bar — decaying A/B Elsasser packets, Kelvin–Helmholtz shear layers and a tearing mode growing magnetic islands in 2D, a counter-propagating Alfvén-wave collision in 3D — which sets the controls and opens the displays that go with them. Everything stays adjustable; presets are configurations, not separate programs (?demo=decay / ?demo=kh / ?demo=tearing / ?demo=collision are deep links to the same thing).

Needs a WebGPU-capable browser (Chrome/Edge 113+, recent Firefox and Safari). Source, implementation contracts (SPEC.md, SPEC3D.md) and the reference-vector generators live in webgpu/ of the jax_rmhd repository.
