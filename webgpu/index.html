Forced reduced-MHD in the browser — WebGPU pseudospectral solvers

a browser port of the jax_rmhd solver · fp32 · no server, no build step

Two live pseudospectral solvers for forced reduced MHD, running entirely on your GPU through WebGPU: the same equations, dealiasing, LSRK33 integrating-factor stepper and Elsasser Ornstein–Uhlenbeck forcing as the JAX code they were ported from, with every kernel written in WGSL. Both pages ship the fp64 reference vectors generated from jax_rmhd itself and a Self-test button that runs them through the same GPU pipelines as production.

They are demos, not science runs: WebGPU has no float64, so expect slow energy-budget drift over long runs. For anything quantitative use the repository's JAX solver.

2D forced RMHD →

rfft2 spectral in (x,y), 128²–512². Vorticity / current / potentials / velocity and magnetic field with an arrow overlay, energy trace, shell-binned spectra, cut trace. Long runs show the 2D inverse cascade piling magnetic energy up at the box scale.

3D forced RMHD, spectral z →

rfftn over (z,x,y), 64²×32 to 256²×64. The Alfvén coupling ±i·kz is applied exactly by a closed-form 2×2 wave propagator, so there is no wave CFL. z-slice or three-face cube view, perpendicular and parallel spectra.
Needs a WebGPU-capable browser (Chrome/Edge 113+, recent Firefox and Safari). Source, implementation contracts (SPEC.md, SPEC3D.md) and the reference-vector generators live in webgpu/ of the jax_rmhd repository.
